# Eye-Tracking Demos

A collection of three experimental browser-based webcam eye trackers, with a simple landing page linking to each demo.

- **[PCA Gaze Tracker](./gazeWebPCA/):** Uses PCA image features, facial landmarks, and personal calibration to estimate gaze.
- **[Hybrid Gaze Tracker](./hybridEyetracker/dist/):** Combines eye and head geometry with personal calibration, heatmaps, and session exports.
- **[WebEyeTrack CNN](./webEyetrackCNN/):** A CNN-based demo with calibration, gaze visualization, and session recording, adapted from [RedForestAI/WebEyeTrack](https://github.com/RedForestAI/WebEyeTrack).
