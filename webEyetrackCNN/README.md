# WebEyeTrack Testing Demo

A browser-based eye-tracking demo adapted from
[RedForestAI/WebEyeTrack](https://github.com/RedForestAI/WebEyeTrack).
All credit for the original WebEyeTrack project, eye-tracking technology, and
underlying implementation belongs to RedForestAI and the original contributors.
Please visit their repository for the original project and documentation.

## Additions for testing

This adaptation adds the following features to test and explore the app:

- **Heatmap:** Visualizes recent gaze positions on the screen.
- **Calibration procedure:** Guides the user through screen targets to test gaze alignment.
- **Session recording:** Records gaze data during a testing session.
- **Data export:** Downloads recorded session data as JSON for further analysis.

## Using the demo

Open the deployed site over HTTPS, allow camera access, and position yourself in
front of the webcam. Use **Calibrate** to follow the calibration targets, enable
**Show Heatmap** to visualize gaze positions, and use **Record**, **Stop**, and
**Export** to capture and download a session.
